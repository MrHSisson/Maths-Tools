# Exam-style question sources

- `spec/` — specification content, extracted from the published spec PDFs into markdown so it can be read without PDF tools. `aqa-discrete.md` holds AQA 7366 (AS) and 7367 (A-level) Discrete mathematics (DA–DG), with an AS / A-level column per statement.
- `sources/` — **git-ignored.** Drop past-paper PDFs here locally (exam-board copyright; never commit them).
- Topic reports (`<topic>.md`) are written from `EXAM_TOPIC_REPORT_TEMPLATE.md` (`docs/design/templates/`) once the questions have been read and checked.
