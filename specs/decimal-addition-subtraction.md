# Adding & Subtracting Decimals

**Status:** implemented — `src/tools/Number/DecimalAddSub.tsx` (live)

Path `/decimal-addition-subtraction` · Category Number · Sub-tools: Adding, Subtracting · Max 3 d.p. · No Teach deck yet.

## Pedagogy
Heavy use of the place value table (shared with Powers of 10 and Comparing & Ordering). Skill: line up the decimal point, fill gaps with placeholder zeros (4.1 = 4.10), then work column by column from the right.

## Levels
| | Adding | Subtracting |
|---|---|---|
| L1 | same d.p., no carrying | same d.p., no exchanging |
| L2 | same d.p., carrying (incl. across the point) | same d.p., exchanging |
| L3 | different d.p.: different d.p. · whole + decimal · answer ends in 0 (3.50 → 3.5) | placeholder zero needed (4.1 − 3.23) · whole − decimal (5 − 2.36) · exchange across a 0 (6.04 − 1.78) · longer number first |

QO: display-only "Table starts" dropdown (Empty / Numbers in / Numbers + zeros; whiteboard & worked example only). L1–2 "Decimal places" pool (1/2/3 d.p.); L3 "Question types" pool per sub-tool.

## Acceptance reference
- 4.1 − 3.23: write → 4.1 = 4.10 → 0−3 exchange (tenth→10 hundredths), 10−3=7 → 0−2 exchange (one→10 tenths), 10−2=8 → 3−3=0 → **0.87**
- 6.04 − 1.78: 4−8 with tenths 0 → exchange one→10 tenths, then tenth→10 hundredths; 14−8=6, 9−7=2, 5−1=4 → **4.26**
- 2.35 + 1.15: 5+5=10 carry 1; 3+1+1=5; 2+1=3 → 3.50 = **3.5**
