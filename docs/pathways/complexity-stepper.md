# Complexity stepper
- **Status:** idea
- **Updated:** 2026-10-28

## Intention
A way for a student to move up through a generator's levels without changing them by hand: questions get harder as they succeed.

## Progress
Not started. It is a student use case, tangled up with Smart Progressor's difficulty bands, and needs a record of how a student is doing and a rule for stepping up or down.
