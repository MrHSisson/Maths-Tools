# Core representations
- **Status:** building
- **Updated:** 2026-10-28

## Intention
Eight shared pictures (bar model, number line, area model, algebra tiles, negative counters, prime factor tiles, place value table, ratio table) used the same way across tools, so a bar model met in fractions reappears in ratio. New visuals must reuse one.

## Progress
- Teach-scene families built: bar model (`split`, `combine`, `equivalents`), number line (`multiples`), prime factor tiles, plus Indices and significant-figures scenes. Not yet: area model, algebra tiles, negative counters.
- Working-step pictures live: place value table (decimals, binary, hex), ratio table (Speed Distance Time), negative counters (`CounterBoard`), the carry ripple. Geometry diagrams and the grapher's labelled `Segment` evolve per step.
- Direction agreed but mostly not built: progressions (double number line to ratio table; counters to signed bar model to number line) and composites (a step carrying two pictures).

## Next steps
- Missing shared components: a signed bar model, a double number line, an Algebra Tiles representation component.
- A representation switch on tools that span a progression; composite visuals (a small extension to `stepVisualRenderer`).
- Open questions: algebra tiles or the area model first (tiles gate more tools)? Do angle / circle / polygon diagrams need their own representation or are they a legitimate exemption? Is the signed bar model a new family or a bar-model variant?
