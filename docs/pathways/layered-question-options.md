# Layered Question Options popover
- **Status:** idea
- **Updated:** 2026-10-28

## Intention
Split the options popover into layers (what is asked, the numbers, notation, method, the answer, support) so a teacher meets a few groups first and opens the rest on demand.

## Progress
Not started. The six tools with 13 to 20 options (Rounding, Comparing & Ordering, Binomial Expansion, File Sizes, Speed Distance Time, Order of Operations) are covered for now by tabs inside the popover (2026-10-27, tested by `qoTabs.test.ts`).

## Next steps
Revisit once those tools' options have been regrouped into the six groups during each tool's review.
