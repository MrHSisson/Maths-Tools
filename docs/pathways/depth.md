# Depth
- **Status:** rolling out
- **Measure:** depth
- **Updated:** 2026-11-01

## Intention
A bank of fixed, hand-written questions a teacher dips into by purpose (diagnose, explain, extend) and level, instead of a rigid slide deck.

## Progress
- A shared ToolShell mode (`depthItems`, the Depth tab) that follows the Question Options: two slides per question (question, then answer), named misconceptions on every wrong option, adaptive "class secure / not secure" links, a cross-level Start here check, deep links, a phone layout and a Present mode.
- A cast of eight named speakers, and Feathers the owl as a mascot only (no speech bubbles, no teacher notes, since 2026-11-01). One shared `DepthSlide` draws a card the same on the tool page and on a deck slide: the question never moves when the answer is shown, the level label stays top-left, speakers alternate left and right, one type scale. A card can be opened and tweaked in a deck (**Edit card**, or **Edit in a deck** from the tool's Depth section); the retired `teacherNote` / `prompt` / `takeaway` fields are gone from every bank.
- Banks live: Order of Operations, Rounding (with a number-line scaffold), Identify Sig. Figs, Speed Distance & Time (all four tabs), Indices. Estimation has a bank used by its deck.
